# Sheet Metal Calculator

A Python Tkinter application to calculate sheet metal bend allowance and flat length.

## Features
- Bend Allowance Calculation
- Flat Length Calculation
- Simple GUI Interface
- Input Validation

## Technologies
- Python
- Tkinter

## How to Run
1. Install Python.
2. Clone or download this repository.
3. Run `SheetMetal Calculator.py`.
